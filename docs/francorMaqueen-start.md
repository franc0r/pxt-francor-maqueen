# start Maqueen

Resets the Maqueen Plus V3 board and waits until it answers.

Shows a check mark when ready.

## Example

```blocks
francorMaqueen.start()
basic.showIcon(IconNames.Happy)
```

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
