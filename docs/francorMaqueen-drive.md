# drive left …% right …%

Drives the left and right wheel. Negative values drive backwards.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.drive(60, 40)
```

## Parameters

In the order of the gaps (…) in the block:

1. Speed of the left wheel in percent, e.g. 50
2. Speed of the right wheel in percent, e.g. 50
