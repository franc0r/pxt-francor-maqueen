# fahre [cm] cm [dir] [wait]

Fährt eine genaue Strecke mit der Regelung der Platine.

Parameter:

* `cm`: Strecke in Zentimetern
* `dir`: vorwärts oder rückwärts
* `wait`: warten, bis die Fahrt fertig ist, oder sofort weitermachen
