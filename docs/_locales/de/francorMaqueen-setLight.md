# setze Licht [led] auf [color]=francor_colors

Setzt eines der vier Lichter unten oder alle.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.setLight(francorMaqueen.Led.One, francorMaqueen.colors(francorMaqueen.Colors.Red))
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `color` | Die Farbe |
| `led` | Welches Licht |
