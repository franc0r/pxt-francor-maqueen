# Ausweich-Abstand … mm

Ab diesem Abstand schlägt der Sensor eine Richtung vor (100 bis 500 mm).

Am Maqueen höchstens 200, sonst sieht der Sensor den Boden.

## Beispiel

```blocks
francorMaqueen.start()
francorLidar.setAvoidDistance(200)
francorLidar.start()
```

## Parameter

* Abstand in mm

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
