# Scheinwerfer [side] Farbe [color]

Stellt die Farbe eines Scheinwerfers ein.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.headlight(francorMaqueen.Side.Both, francorMaqueen.HeadColor.Red)
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `color` | Die Farbe |
| `side` | Welcher Scheinwerfer |
