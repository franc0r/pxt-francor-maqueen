# starte Maqueen

Setzt die Maqueen-Plus-V3-Platine zurück und wartet, bis sie antwortet.

Zeigt einen Haken, wenn sie bereit ist.

## Beispiel

```blocks
francorMaqueen.start()
basic.showIcon(IconNames.Happy)
```

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
