# an Abzweig links [m]

Was der Roboter macht, wo er links abbiegen oder geradeaus fahren kann.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.atLeftOrStraight(francorMaqueen.LeftRule.Straight)
francorMaqueen.patrol(francorMaqueen.OnOff.On)
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `m` | Was er tun soll |
