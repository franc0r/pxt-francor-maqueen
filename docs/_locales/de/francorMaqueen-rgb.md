# rot [r] grün [g] blau [b]

Mischt eine Farbe aus Rot, Grün und Blau.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.setLight(francorMaqueen.Led.All, francorMaqueen.rgb(255, 128, 0))
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `b` | Blau, z. B. 0 |
| `g` | Grün, z. B. 128 |
| `r` | Rot, z. B. 255 |
