# an Abzweig rechts [m]

Was der Roboter macht, wo er rechts abbiegen oder geradeaus fahren kann.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.atRightOrStraight(francorMaqueen.RightRule.Right)
francorMaqueen.patrol(francorMaqueen.OnOff.On)
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `m` | Was er tun soll |
