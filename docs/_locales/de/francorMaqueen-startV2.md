# starte Maqueen V2

Startet den Maqueen Plus V2 und wartet, bis er antwortet.

Zeigt einen Haken, wenn er bereit ist.

## Beispiel

```blocks
francorMaqueen.startV2()
basic.showIcon(IconNames.Happy)
```

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
