# rote LED [side] [on]

Schaltet eine rote LED vorne an oder aus (V2).

## Beispiel

```blocks
francorMaqueen.startV2()
francorMaqueen.redLed(francorMaqueen.Side.Both, francorMaqueen.OnOff.On)
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `on` | An oder aus |
| `side` | Welche LED |
