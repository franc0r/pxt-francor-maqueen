# fahre …%

Fährt mit beiden Rädern gleich schnell. Negative Werte fahren rückwärts.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.driveBoth(50)
basic.pause(1000)
francorMaqueen.stop()
```

## Parameter

* Tempo in Prozent, z. B. 50

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
