# Linien-Tempo [level]

Stellt das Tempo der Linienverfolgung ein.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.patrolSpeed(2)
francorMaqueen.patrol(francorMaqueen.OnOff.On)
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `level` | Stufe von 1 (langsam) bis 5 (schnell), z. B. 1 |
