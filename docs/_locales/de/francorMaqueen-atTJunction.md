# an T-Kreuzung [m]

Was der Roboter an einer T-Kreuzung macht (links und rechts möglich).

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.atTJunction(francorMaqueen.TRule.Left)
francorMaqueen.patrol(francorMaqueen.OnOff.On)
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `m` | Was er tun soll |
