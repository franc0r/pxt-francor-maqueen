# LiDAR einschalten

Schaltet den LiDAR ein. Er misst danach im Hintergrund weiter, dein Programm läuft sofort weiter.

In den ersten Sekunden und ohne Sensor ist der Abstand 9999.

## Beispiel

```blocks
francorMaqueen.start()
francorLidar.start()
```

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
