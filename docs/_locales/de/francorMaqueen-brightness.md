# Licht-Helligkeit [v]

Stellt ein, wie hell die Lichter unten leuchten.

## Beispiel

```blocks
francorMaqueen.start()
francorMaqueen.brightness(60)
francorMaqueen.setLight(francorMaqueen.Led.All, francorMaqueen.colors(francorMaqueen.Colors.White))
```

## Parameter

| Parameter | Bedeutung |
|---|---|
| `v` | Helligkeit von 0 bis 255, z. B. 128 |
