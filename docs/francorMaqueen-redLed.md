# red LED [side] [on]

Turns a red LED on the front on or off (V2).

## Example

```blocks
francorMaqueen.startV2()
francorMaqueen.redLed(francorMaqueen.Side.Both, francorMaqueen.OnOff.On)
```

## Parameters

| Parameter | Meaning |
|---|---|
| `on` | On or off |
| `side` | Which LED |
