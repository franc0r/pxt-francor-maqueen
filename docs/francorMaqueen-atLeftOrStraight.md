# at left-or-straight [m]

What the robot does where it can turn left or go straight.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.atLeftOrStraight(francorMaqueen.LeftRule.Straight)
francorMaqueen.patrol(francorMaqueen.OnOff.On)
```

## Parameters

| Parameter | Meaning |
|---|---|
| `m` | What to do |
