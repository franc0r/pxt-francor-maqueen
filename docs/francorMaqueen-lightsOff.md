# all lights off

Turns all lights off: the four underneath and both headlights.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.setLight(francorMaqueen.Led.All, francorMaqueen.colors(francorMaqueen.Colors.Blue))
basic.pause(1000)
francorMaqueen.lightsOff()
```
