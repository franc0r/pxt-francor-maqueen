# red [r] green [g] blue [b]

Mixes a colour from red, green and blue.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.setLight(francorMaqueen.Led.All, francorMaqueen.rgb(255, 128, 0))
```

## Parameters

| Parameter | Meaning |
|---|---|
| `b` | Blue, e.g. 0 |
| `g` | Green, e.g. 128 |
| `r` | Red, e.g. 255 |
