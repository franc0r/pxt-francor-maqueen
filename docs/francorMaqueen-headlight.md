# headlight [side] color [color]

Sets the colour of a headlight.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.headlight(francorMaqueen.Side.Both, francorMaqueen.HeadColor.Red)
```

## Parameters

| Parameter | Meaning |
|---|---|
| `color` | The colour |
| `side` | Which headlight |
