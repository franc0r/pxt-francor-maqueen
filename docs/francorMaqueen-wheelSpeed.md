# wheel speed … (cm/s)

Speed of a wheel in centimetres per second.

With "both", gives the average.

## Example

```blocks
francorMaqueen.start()
basic.forever(function () {
    basic.showNumber(francorMaqueen.wheelSpeed(francorMaqueen.Side.Both))
})
```

## Parameters

* Which wheel
