# Colour

Gives you a colour.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.setLight(francorMaqueen.Led.All, francorMaqueen.colors(francorMaqueen.Colors.Green))
```

## Parameters

* The colour

```package
francor-maqueen=github:franc0r/pxt-francor-maqueen#v0.1.4
```
