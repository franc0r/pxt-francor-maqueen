# drive …%

Drives both wheels at the same speed. Negative values drive backwards.

## Example

```blocks
francorMaqueen.start()
francorMaqueen.driveBoth(50)
basic.pause(1000)
francorMaqueen.stop()
```

## Parameters

* Speed in percent, e.g. 50
