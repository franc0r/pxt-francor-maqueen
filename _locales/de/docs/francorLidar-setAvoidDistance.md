# Ausweich-Abstand [mm] mm

Ab diesem Abstand rät der Sensor eine Richtung (100 bis 500 mm). Am Maqueen höchstens 200, sonst sieht der Sensor den Boden.

Parameter:

* `mm`: Abstand in mm
